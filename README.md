## 一、RP2040 移植：第一阶段逻辑适配

本次修改基于提供的 `2040TX` 原始项目。

**注意：本阶段代码尚未在用户实际使用的 Arduino-Pico 开发环境中完成编译，也尚未在真实遥控器硬件上进行测试。**

### 1. 摇杆输入方式调整

- 四路摇杆输入改为使用 RP2040 自身 ADC，通过 `analogRead()` 读取。
- ADC 引脚采用可配置方式。
- 显式设置 `analogReadResolution(12)`，使用 12 位 ADC 分辨率。
- 摇杆校准数据保存原始硬件 ADC 数值（0～4095）。
- `calibrate()` 将原始 ADC 数据映射至原遥控器逻辑范围（0～2047）。
- 保留原有的死区、Expo 和通道计算公式，避免改变原有控制逻辑。
- 对旧版 ADS1115 摇杆校准数据进行范围检查，超出范围时恢复默认值。
- 安装此版本后，需要重新执行摇杆校准。

### 2. 电池电压测量调整

- ADS1115 保留，仅用于本机电池电压测量。
- 使用 ADS1115 的 A0 通道。
- ADS1115 设置为连续转换模式。
- 主循环以较低频率读取最近一次转换结果，避免等待 ADC 转换造成阻塞。
- 电压分压计算使用原有的 33kΩ / 10kΩ 电阻参数。
- 保留原有 `Volt Scale` 反向校准机制，默认值为 454。

### 3. I2C 总线初始化调整

- 将 `Wire.setSDA()`、`Wire.setSCL()` 和 `Wire.begin()` 移至 OLED 与 ADS1115 初始化之前。
- OLED 与 ADS1115 共用 I2C 总线。
- OLED I2C 时钟设置为 400 kHz，以兼顾共用总线时的稳定性。

### 4. CRSF 接收解析优化

- 将原有等待完整遥测数据帧的阻塞式接收方式，改为增量式数据解析。
- 支持跨多次调用保留未接收完整的数据帧。
- 增加不完整数据帧的超时处理。
- 保持原有 CRSF CRC、数据包格式、通道打包方式、ELRS 状态机以及 Lua 参数协议不变。
- 在 `hardware.h` 中通过 `ELRS_UART` 统一选择 UART 对象，避免重复定义串口对象。
- 显式初始化 CRSF 时间及同步状态变量。

### 5. 配置数据保存优化

- 缓存 LittleFS 挂载状态，避免重复调用 `begin()`。
- 配置读写增加实际字节数检查。
- 增加读取配置后的数据有效性验证。
- 恢复原有死区设置范围（0～200，逻辑比例为 /2048）。
- 对超出原有范围的实验性配置进行限制，而不是直接清除全部设置。

### 6. 第一阶段编译和硬件测试注意事项

- `STICK_ADC_*_PIN` 当前使用临时默认引脚，最终需要根据实际硬件接线确定。
- 如果需要显示本机电池电压，ADS1115 的 A0 必须连接至电池分压输出端。
- Arduino-Pico Core、U8g2 和 Adafruit ADS1X15 的实际版本仍需确认。
- 本阶段尚未完成真实编译和硬件验证。

## 二、OLED 简体中文汉化（2026-10-29）

### 修改内容

- 新增 `locale_zh_cn.h`，用于实现 OLED 显示文本的英文到简体中文转换。
- 汉化遥控器设置菜单及常见 ELRS 菜单名称和选项。
- `config.cpp` 中的内部英文标签保持不变。

### 兼容性说明

`Handset::saveGlobalSettings()` 使用内部英文标签作为配置保存的键值。

因此，本次汉化仅修改显示文本，不修改内部配置标签，避免影响 LittleFS 设置兼容性，也不改变二进制配置数据结构及版本。

### OLED 字体及显示方式

- 使用 U8g2 的 UTF-8 绘制接口：
  - `drawUTF8()`
  - `getUTF8Width()`
- 使用随项目集成的中文字体：
  - `u8g2_font_wqy12_t_gb2312`

### 汉化范围

- 遥控器设置菜单及选项。
- 通道输出页面标题。
- ELRS 状态信息。
- BLE 摇杆页面。
- 摇杆校准提示。
- 命令弹窗提示。

对于无法确认的模块专用 ELRS 文本，保留原始英文，避免错误翻译或显示异常。

### 字体资源说明

字体数据表约占用 202,690 字节。

这是字体数据在程序 Flash 中的资源大小，并不代表需要占用同等大小的 RAM。

实际链接保留情况和最终固件大小，需要通过 RP2040 实际编译确认。

### 测试状态

本次修改仅完成静态源码检查，尚未实际编译或进行硬件测试。

后续需要验证：

- 中文字形覆盖是否完整。
- OLED 页面是否存在文字溢出或裁切。
- RP2040 Flash 空间是否足够。

## 三、设置保存功能修复（2026-10-29）

### 问题说明

原有手柄设置使用 LittleFS 文件系统保存。

当 LittleFS 挂载失败时，菜单修改后的设置无法正确保存，导致重新读取时恢复为默认值。

### 修改内容

- 将手柄设置的 LittleFS 文件保存方式改为 EEPROM 模拟存储。
- 从 EEPROM 偏移地址 128 开始保存手柄设置。
- 摇杆校准数据继续保存在 EEPROM 偏移地址 0。
- 两部分数据存储区域互不重叠，摇杆校准结构体占用 48 字节。
- 增加数据 Magic 标识。
- 增加版本及数据范围检查。
- 增加写入后回读验证。
- 增加 Serial 串口诊断信息。

### 当前状态

本次修改属于源码层面的修复，仍需在用户实际使用的 Arduino-Pico 开发板核心环境中完成编译和硬件验证。

## 四、接收机电池电压遥测及 OLED 显示

### 1. CRSF 电池遥测解析

- 增加 CRSF 电池传感器遥测数据解析。
- 电池遥测帧类型为 `0x08`。
- 直接读取 CRSF 提供的 0.1V 电压数据。
- 接收机电池电压不使用本机 `Volt Scale` 校准参数。

### 2. OLED 电压显示

OLED 电压显示区域采用两个小写 `v` 标识区分不同的电压来源：

- 下方 `v`：表示遥控器本机电池电压。
- 上方 `v`：表示接收机回传电池电压。

显示每隔 3 秒自动切换一次。

### 3. 遥测超时处理

- 接收机电压遥测超过 3 秒没有收到新数据时，判定为无效。
- 无有效遥测数据时，接收机电压显示为 `-.-`。
- 本机 ADS1115 电压检测及原有校准机制保持不变。
